# 作品集 Case｜主图短视频优化（另一品）

**吴林栩（Cici）** · 电商视觉 / 内容策略 · 窗口 **6/17–9/13**（基准 → 一期 → 二期）  
**独立声明：** 本包为**另一品**酒店折叠床主图视频优化；与「主图 A/B + 详情页」案例包**证据独立**，**禁止**串成「同品：主图验证 → 视频补全 → 详情承接」。

---

## 背景 / 问题

旧版主图视频以「操作演示」为主（展开/收起、手压回弹），缺少客房场景与完整使用体验，用户难判断是否适合客房加床。  
基准期（6/17–7/16）：加购率 **6.87%**、支付转化率 **0.81%**、跳失率 **90.87%**。

---

## 动作

将表达从「床怎么动」转向「床放进客房后怎么用」：

1. 加入酒店客房、主床及家具参照  
2. 补充铺好寝具的成品床位 + 人物坐躺  
3. 保留功能细节、弱化大面积字幕干扰  

上线后按两期跟踪（一期约 28 天、二期约 31 天），并核对日均曝光与经营变量（旺季、推广）。

**效率折算（支付）**

| 口径 | 含义 |
|------|------|
| 每 1000 曝光 | 支付约 **8.1 → 15.7** 人 |
| 6610 曝光口径 | 0.76pt 提升 ≈ **+50** 支付效率差额 |

**读法：** 读效率不读总量（期天数不同）；日均曝光回落时转化仍升 → 不全是流量堆出来的。  
**边界：** 7–8 月旺季 + 推广加码；8 月较 7 月销售额 **+79.31%**，费比 **21.6%→17.53%**。视觉与经营变量**未完全拆分** → 可说「同向 + 曝光回落时效率仍升」，**不能**说「视频带来全部增长」。

**下一步产品选择（已发生判断）：** 可先保持方向；若再优化优先补展开/折叠、弹力失真、镜头承接。成本量级：局部 3D 约 **600 元**；整条重制约 **800–2000 元/条** → 先局部验证再决定是否重制。
